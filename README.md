# golden_cross

25日移動平均線が75日移動平均線を上抜けた（ゴールデンクロスした）日本株を探し、出来高の多い順に表示する CLI ツールです。

## インストール

Rust のツールチェインが必要です（開発時は 1.98.0、edition 2024）。

```bash
cargo build --release      # target/release/golden_cross に生成される
cargo install --path .     # パスの通った場所へ入れる場合
```

## 使い方

```
Usage: golden_cross [OPTIONS]
```

| オプション | 説明 | 既定値 |
|---|---|---|
| `-t`, `--top <N>` | 表示する件数 | `10` |
| `-w`, `--within <DAYS>` | 何営業日以内のクロスを対象にするか | `5` |
| `-c`, `--concurrency <N>` | 同時に取得する銘柄数（1〜16） | `8` |
| `-s`, `--symbols <...>` | 走査する銘柄コード（省略時は同梱リスト） | — |
| `--show-errors` | 取得に失敗した銘柄を一覧表示する | — |
| `--no-cache` | キャッシュを使わず必ず取得し直す | — |

```bash
golden_cross                          # 直近5営業日のクロスを出来高上位10件
golden_cross --within 20              # 直近20営業日まで広げる
golden_cross --top 3                  # 上位3件だけ表示
golden_cross --symbols 7203.T 6758.T  # 対象を指定して調べる
```

### 終了コード

| コード | 意味 |
|---|---|
| 0 | 正常終了（該当0件でも 0） |
| 1 | 全銘柄の取得に失敗 |
| 2 | 引数が不正 |

表は標準出力、進捗と警告は標準エラー出力に出るため、リダイレクトすると表だけを残せます。進捗表示は端末のときだけ出ます。

```bash
golden_cross > result.txt
```

## キャッシュ

取得したレスポンスを `~/.cache/golden_cross/` に保存し、**同じ日のうちは再利用**します（`XDG_CACHE_HOME` があればそちらの下）。日足データは1日1回しか変わらないためです。

```
1回目: 7.9秒（239リクエスト）
2回目: 0.0秒（0リクエスト）
```

**注意: 株価と出来高はキャッシュ取得時点の値になります。** 終値と移動平均、クロス判定は日中に変わりませんが、現在値と出来高はザラ場中も動きます。最新の値が必要なときは `--no-cache` を付けてください。

キャッシュの読み書きに失敗しても処理は止めません。壊れたファイルは読み飛ばして取得し直します。不要になったら `rm -rf ~/.cache/golden_cross` で削除できます（約4MB）。

## 判定方法

前日に「25日線 ≦ 75日線」だったものが、当日「25日線 > 75日線」になった日をゴールデンクロスとみなします。複数回クロスしている場合は**最も新しいもの**を採用し、それが `--within` 営業日以内なら対象とします。

移動平均は終値の単純移動平均（SMA）です。75日分そろわない期間は判定しません。データは1年分（約244営業日）を取得しています。

## 走査対象について

**同梱の主要銘柄リスト（東証239銘柄）の範囲で順位付けします。市場全体のランキングではありません。**

Yahoo Finance には日本株の出来高ランキングを返すエンドポイントがないためです（predefined screener は米国株専用で `region=JP` が効かず、カスタム検索は crumb 認証が必要）。

リストは `data/universe.tsv` にあり、コンパイル時にバイナリへ埋め込まれます（`include_str!`）。1行が「銘柄コード <TAB> 名称」です。全銘柄が実際に API から取得できることを確認済みです。

対象を変えたい場合は `--symbols` で指定してください。

### 構成

```
data/
└── universe.tsv    走査対象の銘柄一覧（バイナリへ埋め込み）

src/
├── main.rs         エントリポイント（引数 → 並列取得 → 絞り込み → 表示）
├── cli.rs          コマンドライン引数の定義（clap）
├── universe.rs     銘柄一覧の読み込み
├── cache.rs        取得結果のディスクキャッシュ
├── stock.rs        株価の型と移動平均の計算
├── cross.rs        ゴールデンクロスの判定
├── sanitize.rs     端末へ出力する文字列の無害化
├── yahoo/          株価の取得
│   ├── mod.rs        fetch() — HTTP と、API 形式 → 内部型への変換
│   └── model.rs      レスポンスを受ける構造体（serde）
└── output/         標準出力への表示
    ├── mod.rs        再公開のみ
    └── table.rs      表の組み立て
```

[stocks_cli](https://github.com/itomofumi/stocks_cli) と同じ構成方針です。`yahoo` が API の形式を `stock::Stock` に詰め替えて返すため、`cross` や `output` は Yahoo のレスポンス構造を知りません。

### 主な依存クレート

| クレート | 用途 |
|---|---|
| [clap](https://crates.io/crates/clap) | コマンドライン引数のパースと検証 |
| [reqwest](https://crates.io/crates/reqwest) | HTTP クライアント（blocking + rustls） |
| [serde](https://crates.io/crates/serde) | JSON のデシリアライズ |
| [chrono](https://crates.io/crates/chrono) | UNIX 秒から JST への変換、キャッシュの日付判定 |
| [serde_json](https://crates.io/crates/serde_json) | キャッシュした本文の解釈 |

## 注意

**非公式のエンドポイントを利用しています。** Yahoo 側の仕様変更や遮断により動作しなくなる可能性があります。ゴールデンクロスは過去の価格から機械的に算出した指標にすぎず、**投資判断に用いないでください**。
